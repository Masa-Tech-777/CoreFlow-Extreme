# CoreFlow Extreme

[English README](README_EN.md)

CoreFlow Extremeは、Windows 11（x64）でCPUの動作を用途に合わせて調整するアプリです。たとえば、ACアダプター接続中は性能を優先し、バッテリー駆動中は最大周波数を低めに設定できます。

## 主な機能

- AC接続時とバッテリー駆動時に、最大周波数（MHz）、最小周波数の目安、ブーストモードを個別に設定できます。
- 選んだWindows電源プランの複製に設定を適用します。元のプランのCPU設定を保ったまま試せます。
- 適用後15秒以内に［この設定を維持］を押すと確定します。確認せずに時間が過ぎると、直前の状態に戻ります。
- 付属のMonitorで、観測クロック、CPU使用率、現在の制御状態を確認できます。温度表示には対応モジュールが必要です。

## 使い始める

1. 配布ZIPをフォルダーごと展開します。旧版が起動中なら、先に［終了して復元］で終了します。
2. `CoreFlow_Extreme.exe` を起動し、Windowsの管理者確認を承認します。`LiveMonitor` フォルダーは本体と同じ場所に置いてください。
3. 設定する電源プランを選び、AC／バッテリーの設定を確認して［設定を適用］を押します。最初は最大周波数だけを少しずつ調整すると、変化を確認しやすくなります。
4. 問題なければ［この設定を維持］を押します。アプリを完全に終了して通常の電源プランへ戻すには、通知領域のアイコンを右クリックし、［終了して復元］を選びます。右上の［×］で閉じると通知領域に常駐し、制御を続けます。

## 周波数の見方

最大周波数は10 MHz刻みで指定でき、0 MHzで上限指定を解除します。最小周波数は400 MHz以上を10 MHz刻みで入力できます。ブーストモードはWindowsの7種類（0～6）から選べます。CPU仕様データベースで最大値を確認できた場合は、その値が入力上限です。

確定した設定は元の電源プランごとに保存します。Windowsで通常の電源プランを選ぶと、Extremeの制御は停止します。本体から設定を適用すると再開できます。

最大周波数は、Windowsに指定する上限です。最小周波数の入力値は、Windowsの最小プロセッサ性能（％）への換算に使います。実際のクロックや設定の効果は、CPU、負荷、PCメーカーの制御などによって異なります。Monitorの観測クロックはWindowsによる区間推定値です。詳しくは配布ZIP内の「使い方_JP.txt」をご覧ください。

## 最大周波数とブーストを一緒に使う

たとえば、公称最大4.9 GHzのCPUで上限を3800 MHzに設定し、ブーストを有効にしておくと、対応環境ではWindowsとCPUがその設定を踏まえて負荷に応じて動作します。動画視聴や文書作業では低めの上限から試し、処理の待ち時間が気になる場合は少しずつ上げると、性能とファン音の変化を比べやすくなります。ACとバッテリーには別々の値を保存できます。

上限は動作を3800 MHzへ固定する設定ではありません。瞬間的な観測値も含めて常に指定値以内に収まることは保証されません。最小周波数の400 MHzも、実際に400 MHzまで下がることや、400 MHzを下回らないことを保証する値ではありません。

## ブーストモードの選び方

| 値 | モード | 動作方針 |
|---|---|---|
| 0 | 無効 | ブーストを無効にします。 |
| 1 | 有効（標準） | Windowsの標準的なブースト動作を使います。 |
| 2 | アグレッシブ | より積極的に性能を要求します。 |
| 3 | 効率的な有効化 | 効率を考慮してブーストを使います。 |
| 4 | 効率的なアグレッシブ | 効率を考慮しつつ、積極的に性能を要求します。 |
| 5 | アグレッシブ（保証） | 保証性能レベルを基準に積極的に性能を要求します。 |
| 6 | 効率的なアグレッシブ（保証） | 保証性能レベルを基準に効率も考慮して性能を要求します。 |

実際の応答はCPUやファームウェアによって変わります。はじめは現在のモードのまま上限だけを変更すると、それぞれの影響を確認しやすくなります。

## 入力値の確認と補正

CPU型番が内蔵データベースと一致すると、公称の基本周波数と最大周波数を表示します。確認済みの上限を超えて入力したときは、入力欄を上限まで戻します。空欄、400 MHz未満の最小周波数、1～800 MHzの最大周波数は1400 MHzへ補正します。実機検証に基づく回避処理として、2500 MHzは2400 MHzへ補正します。補正の案内が出たときは値を見直し、改めて［設定を適用］を押してください。最大周波数が0以外の場合、最小周波数は最大周波数より低く設定します。

## 終了・復元と設定の保存

［終了して復元］で通常の電源プランに戻り、Extremeの専用プランを片付けます。確定した設定とライセンス登録は保存され、正常終了後に本体を起動すると確定済みの設定を再適用します。異常終了後は復元を優先します。［完全初期化］を選ぶと、登録済みライセンスと保存した設定も消去されます。

## Monitorと診断ログ

［モニターを表示］で動作状況を確認できます。別途導入したHWiNFOを使う場合は、本体の［ヘルプ］で実行ファイルを登録すると、Monitorから起動できます。不具合を報告するときは、本体の［診断ログを保存…］とMonitorの診断ログに、発生時刻、電源プラン、AC／バッテリーの別を添えてください。
